3A · One price-taking firm: cost curves and the profit-maximising output

In perfect competition the firm is a price taker: it can sell as much as it likes at the market price, so marginal revenue (MR) = price. It keeps producing while the next unit adds more revenue than cost, and stops where MR = MC. Drag the price line up and down. The shaded box is profit (green) or loss (red).

Things to try
  • Raise the price and see the output slide up along the MC curve. That’s why MC (above the shutdown point) is the firm’s supply curve.
  • Drop the price below the ATC minimum: the firm makes a loss but should still produce if price ≥ AVC (it covers some fixed costs). Below AVC, shut down and lose only the fixed cost.
  • In the total view, the profit gap is largest where the dashed line (slope = MC) is parallel to the revenue line (slope = P). That’s the same MR = MC rule seen another way.
  • Raise fixed cost: ATC moves up but MC doesn’t — so the output decision is unchanged; only profit falls. (Fixed costs are sunk.)

3B · The whole market: how competition erodes profit

Market supply is the sum of all firms’ MC curves (above shutdown). If firms make profit, others enter: supply shifts right, price falls. If they make losses, firms exit. It stops at zero economic profit where P = minimum ATC. Try a demand boom, then press Auto-run.

The market

A typical firm

Things to try
  • Set very few firms: the price is high and each firm earns a fat profit. Press “Auto-run” and watch entry push price down.
  • Press “Reset”, then increase market demand. Short-run profits appear → entry → in the long run price returns to minimum ATC, but with more firms and more output.
  • Set too many firms and watch exit happen.

Key takeaways

  • Fixed costs don’t change with output; variable costs do. ATC = AFC + AVC. MC cuts AVC and ATC at their minimums.
  • Profit-maximising rule for any firm: produce where MR = MC (and only if P ≥ AVC).
  • For a price-taker MR = P, so P = MC. The firm’s supply curve is MC above min AVC.
  • Short-run profit invites entry; in the long run P = min ATC and economic profit is zero. Zero economic profit still means normal returns to the owners.
